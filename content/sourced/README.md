# Sourced knowledge pages

English canonical source pages. Do not machine-translate into zh/pt/ar/ru until a real translation exists.

Each folder:

- `source.json` — metadata, sources, answer block, contentStatus
- `content.md` — publishable body only. If sources are missing, set `contentStatus` to `needs-manual-content` and leave a TODO in markdown. Do not fill with AI copy.

Numbers in `content.md` must trace to Pinjin catalogue rows, ACPA/ACI public guidance, or an explicit marketplace observation (cite the URL, do not copy listing copy).
